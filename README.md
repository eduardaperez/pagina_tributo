# Página Tributo – The Offspring

## 🎸 Descrição

Este projeto é uma **página tributo** à banda **The Offspring**, desenvolvida para praticar os fundamentos de **HTML** e **CSS**. A página apresenta informações sobre a banda, incluindo sua história, discografia e imagens.

## 🛠 Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo da página.
- **CSS3**: Estilização e layout da página.

## 📂 Estrutura do Repositório

- `index.html`: Arquivo principal contendo o conteúdo da página.
- `css/`: Diretório contendo os arquivos de estilo CSS.
- `img/`: Diretório contendo as imagens utilizadas na página.

## 🚀 Como Visualizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/eduardaperez/pagina_tributo.git
   
2. Navegue até o diretório do projeto:
   
   ```bash
    cd pagina_tributo

3. Abra o arquivo index.html em seu navegador favorito.
